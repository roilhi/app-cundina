### Novedades principales

1. Configuración individual por ahorrador
Cada persona tiene su propio campo para indicar cuántos turnos (quincenas) quiere recibir

Puedes asignar desde 1 hasta el total de quincenas disponibles

2. Validación inteligente
El sistema calcula automáticamente la suma total de turnos asignados

Te muestra en tiempo real si faltan, sobran o está correcto

No permite hacer el sorteo hasta que la suma coincida exactamente

3. Algoritmo justo de sorteo
Crea un "pool" donde cada ahorrador aparece tantas veces como turnos solicitó

Mezcla aleatoriamente tanto los nombres como las quincenas

Asigna respetando exactamente la cantidad de turnos que pidió cada persona

4. Interfaz mejorada
Tarjetas individuales para cada ahorrador

Indicador visual del total de turnos (verde ✅, amarillo ⚠️, rojo ❌)

Tabla de resultados numerada y ordenada cronológicamente

📝 Ejemplo de uso
Escenario:

3 ahorradores: Ana, Luis, María

Total quincenas: 6

Ana quiere 1 turno, Luis quiere 2 turnos, María quiere 3 turnos

Total: 1+2+3 = 6 ✅

Resultado esperado:

Ana recibe EXACTAMENTE 1 quincena aleatoria

Luis recibe EXACTAMENTE 2 quincenas diferentes

María recibe EXACTAMENTE 3 quincenas diferentes

Todas las 6 quincenas se asignan sin repetir
